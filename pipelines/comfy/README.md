# ComfyUI workflows (S3)

One API-format workflow JSON per graph, generated by `scripts/make_comfy_workflows.py` (`make workflows`; never
hand-edit node ids). The worker fills values by name through each file's `meta.inputs` and reads results through
`meta.outputs`; the GenAI profile (`config/genai/<profile>.yaml`) says which file each stage runs.
`meta.validated` records the host and date of a workflow's first clean run.

| File | Stage | Main inputs | Outputs | Runs on |
| --- | --- | --- | --- | --- |
| `01_concept_front.json` | B | `positive`, `negative`, `seed`, `depth_image`, `init_image` | `concept` | proxy-controlled concept (S3 fallback) |
| `01b_concept_txt2img.json` | B | `positive`, `negative`, `seed`, `width`, `height` | `concept` | both real profiles (decision 86) |
| `02_views_ipadapter.json` | C | `concept_image`, `depth_{front,left,back,right}`, `positive_{...}` | `view_{front,left,back,right}` | nvidia-24gb until S6 |
| `02b_views_mvadapter.json` | C | `concept_image`, `positive`, `negative`, `mv_*` model paths | `view_{front,left,back,right}` | mac-m4pro (decisions 95, 96) |
| `03_shape_hy2mv.json` | D | `view_{front,left,back,right}`, `seed`, `steps`, `octree_resolution`, `sampler`, `mesh_algorithm` | `shape` (GLB) | both real profiles |
| `03b_shape_hy21_single.json` | D (fallback) | `view_front`, `seed` | `shape` (GLB) | nvidia-24gb (the Mac's fallback is the shape server) |
| `04_texture_hy_paint.json` | F (texture) | `mesh_path`, `ref_image` | `albedo` | nvidia-24gb, opt-in |
| `05_matte_birefnet.json` | B/C (matting) | `image`, `bg_model` | `mask` | both real profiles (decision 98) |

The adapters live in `backend/worker/backends/real/comfy.py`; model weights are pinned in `models.yaml` and
fetched with `make models` (NVIDIA) or `make -C mac models` (Mac).
